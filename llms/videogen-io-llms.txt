# VideoGen API

> HTTP API with TypeScript and Python SDKs for generating videos with VideoGen. The core surface is end-to-end video workflows (script-to-video, voiceover-to-video, slideshow-to-video): `POST /v1/workflows/*` creates a project and renders a finished video with visuals, narration, and captions. Poll workflow runs, list and export projects, and subscribe to `workflow_run.*` webhooks. The API also exposes standalone asynchronous media tools (generate-image, generate-video-clip, text-to-speech, generate-sound-effect, generate-music, generate-motion-graphic, generate-avatar, image/video upscaling, background removal, vectorization), file management, reusable entities (characters and visual styles), an asynchronous AI Assistant chat API, avatar/TTS/language catalogues, and an account lookup (`GET /v1/me`) for connection tests. Authentication uses a bearer API key or, for apps acting on behalf of other VideoGen users, an OAuth 2.1 access token ("Sign in with VideoGen"). Base URL: `https://api.videogen.io/v1`. All numeric timestamp fields (`expiresAt`, `occurredAt`, `createdAt`, etc.) are seconds since the Unix epoch (UTC). Machine-readable API spec: `/openapi.json` and `/openapi.yaml`. MCP docs surface for AI clients: `/_mcp/server`.

## Workflows

- [Script to video](https://docs.videogen.io/rest-api-reference/workflows/script-to-video.md): Create a project and render a narrated video from a script, used verbatim. The primary entry point.
- [Voiceover to video](https://docs.videogen.io/rest-api-reference/workflows/voiceover-to-video.md): Build a video from an uploaded voiceover file (upload via the Files API first).
- [Slideshow to video](https://docs.videogen.io/rest-api-reference/workflows/slideshow-to-video.md): Build a narrated video from an uploaded PDF or PowerPoint file.
- [Prompt to video clip](https://docs.videogen.io/rest-api-reference/workflows/prompt-to-video-clip.md): Create a project and generate one short AI video clip from a text prompt (opening frame, then animate).
- [List workflow runs](https://docs.videogen.io/rest-api-reference/workflows/list-workflow-runs.md): List workflow runs, most recent first. Cursor-paginated; see [Pagination](https://docs.videogen.io/pagination.md).
- [Get workflow run status](https://docs.videogen.io/rest-api-reference/workflows/get-workflow-run.md): Poll a workflow run by `workflowRunId` for status, progress, and `projectId` (plus optional `projectUrl` for the app editor).
- [Cancel a workflow run](https://docs.videogen.io/rest-api-reference/workflows/cancel-workflow-run.md): Request cancellation of an in-progress workflow run.

## Projects

- [List projects](https://docs.videogen.io/rest-api-reference/projects/list-projects.md): List projects, most recently updated first (`selfOnly` scopes to the key owner; API-created only by default, pass `includeUiProjects=true` for dashboard projects too). Cursor-paginated; see [Pagination](https://docs.videogen.io/pagination.md).
- [Get project metadata](https://docs.videogen.io/rest-api-reference/projects/get-project.md): Title, aspect ratio, status, and optional `projectUrl` (app editor link; use `projectId` for API-only flows).
- [Export a project as MP4](https://docs.videogen.io/rest-api-reference/projects/export-project.md): Start an MP4 export; returns an `exportId`.
- [List project exports](https://docs.videogen.io/rest-api-reference/projects/list-project-exports.md): List a project's export ids, newest first.
- [Get project export](https://docs.videogen.io/rest-api-reference/projects/get-project-export.md): Poll an export by `exportId`. When `status` is `succeeded` it returns `downloadUrl`/`thumbnailUrl` plus the full hydrated export `file`. Those signed URLs are private and valid for 7 days (`downloadUrlExpiresAt` / `thumbnailUrlExpiresAt`); they are re-signed automatically when within an hour of expiry, so re-fetching always returns a valid URL. Single-resource GETs auto-rehydrate this way; list endpoints (`GET /v1/tools/executions`, `GET /v1/files`, `GET /v1/workflows/runs`) do not re-sign, so a listed URL may be expired (check `downloadUrlExpiresAt`). GET the individual resource or use the file endpoints (`GET /v1/files/{fileId}`, `POST /v1/files/{fileId}/hydrate`) to refresh. `exportFileId` lets you hydrate fresh URLs directly from the file later.
- [Apply remix actions to a project](https://docs.videogen.io/rest-api-reference/projects/remix-project.md): Apply an ordered list of edits (background music, logo, captions, transitions, natural-language edits) to a project.
- [List remix actions for a project](https://docs.videogen.io/rest-api-reference/projects/list-project-remix-actions.md): Every remix action applied to a project, most recent first, with status and progress.
- [Create a timeline interchange](https://docs.videogen.io/rest-api-reference/projects/create-timeline-interchange.md): Convert a project into an editor interchange document (Final Cut Pro XML, Adobe Premiere Pro, or OpenTimelineIO). Returns an `interchangeJobId` to poll.
- [Get timeline interchange job](https://docs.videogen.io/rest-api-reference/projects/get-timeline-interchange.md): Poll a timeline interchange job by `interchangeJobId` for status and the resulting interchange document.

## Assistant

- [Start an assistant chat](https://docs.videogen.io/rest-api-reference/assistant/start-assistant-chat.md): Start an asynchronous AI Assistant chat from a message; creates a project and returns `{ messageId, assistantId, projectId, projectUrl }`. Poll `messageId` for the pending reply.
- [Get an assistant chat](https://docs.videogen.io/rest-api-reference/assistant/get-assistant.md): Retrieve an assistant chat by `assistantId`, including its messages, suggested actions, and current state.
- [Send an assistant message](https://docs.videogen.io/rest-api-reference/assistant/send-assistant-message.md): Send a follow-up message to an existing assistant chat; returns a `messageId` to poll.
- [Get an assistant message](https://docs.videogen.io/rest-api-reference/assistant/get-assistant-message.md): Poll an assistant message by `messageId` for status and the assistant's response.
- [Act on an assistant action](https://docs.videogen.io/rest-api-reference/assistant/act-on-assistant-action.md): Apply a suggested action returned by the assistant (`actionId`) to the chat's project.

## Tools

- [Generate image](https://docs.videogen.io/rest-api-reference/tools/generate-image.md): Generate images from a text prompt, or transform an existing image.
- [Generate video clip](https://docs.videogen.io/rest-api-reference/tools/generate-video-clip.md): Generate a single short standalone video clip (up to 30 seconds) from text, an image, or a video. VideoGen automatically routes each request to a suitable video generation model.
- [Text to speech](https://docs.videogen.io/rest-api-reference/tools/text-to-speech.md): Synthesize speech audio from text using a TTS voice. Only voices with `supportsDirectToolExecution` set to true can be used.
- [Generate sound effect](https://docs.videogen.io/rest-api-reference/tools/generate-sound-effect.md): Generate a sound-effect audio clip from a text prompt.
- [Generate music](https://docs.videogen.io/rest-api-reference/tools/generate-music.md): Generate an instrumental music track from a text prompt describing genre, mood, instrumentation, and tempo.
- [Generate motion graphic](https://docs.videogen.io/rest-api-reference/tools/generate-motion-graphic.md): Generate an animated motion graphic video from a text prompt (experimental, agentic). Best for precise text animations like typing effects and kinetic typography.
- [Generate avatar](https://docs.videogen.io/rest-api-reference/tools/generate-avatar.md): Render an ACTOR entity (`actorEntityId`) speaking an uploaded audio file. Optionally select `avatarQuality` (`LOW`, `STANDARD`, `HIGH`, or `MAX`). The request requires `audioFileId` plus exactly one avatar source.
- [Vectorize image](https://docs.videogen.io/rest-api-reference/tools/vectorize-image.md): Convert a raster image into vector (SVG) output.
- [Remove image background](https://docs.videogen.io/rest-api-reference/tools/remove-image-background.md): Produce a transparent-background version of an image.
- [Remove video background](https://docs.videogen.io/rest-api-reference/tools/remove-video-background.md): Produce a transparent-background version of a video.
- [Upscale an image](https://docs.videogen.io/rest-api-reference/tools/upscale-image.md): Increase the resolution of an existing image.
- [Upscale a video](https://docs.videogen.io/rest-api-reference/tools/upscale-video.md): Increase the resolution of an existing video.
- [Add 3D motion to an image](https://docs.videogen.io/rest-api-reference/tools/image-3-d-effect.md): Turn a still image into a short video clip with a 3D parallax motion effect.
- [List tool executions](https://docs.videogen.io/rest-api-reference/tools/list-tool-executions.md): List tool executions, newest first. Cursor-paginated; see [Pagination](https://docs.videogen.io/pagination.md). Listed signed URLs are not re-signed, so GET the individual execution to refresh an expired URL.
- [Get tool execution info](https://docs.videogen.io/rest-api-reference/tools/get-tool-execution-info.md): Poll a tool execution by `toolExecutionId` for status and result. Each succeeded result carries convenience `downloadUrl`/`thumbnailUrl` (with `*ExpiresAt`) at the top level alongside the full hydrated `file`. Signed URLs are valid for 7 days and this single-execution GET re-signs them automatically when within an hour of expiry, so re-fetching always returns a valid URL (the list endpoint does not re-sign). Executions remain retrievable indefinitely, including those older than 7 days.
- [Cancel tool execution](https://docs.videogen.io/rest-api-reference/tools/cancel-tool-execution.md): Request cancellation of an in-flight tool execution.

- [Create file upload](https://docs.videogen.io/rest-api-reference/files/create-file-upload.md): Create a pending file and get a presigned upload URL. PUT file bytes to the URL to complete the upload.
- [Hydrate file](https://docs.videogen.io/rest-api-reference/files/hydrate-file.md): Generate fresh signed URLs for thumbnails, previews, and downloads. Call when source URLs are missing or expired.
- [Enable public preview](https://docs.videogen.io/rest-api-reference/files/enable-public-preview.md): Enable public preview for a file. Creates a public playback ID so the file can be streamed without authentication.
- [Disable public preview](https://docs.videogen.io/rest-api-reference/files/disable-public-preview.md): Disable public preview for a file. Removes the public playback ID.
- [Search files](https://docs.videogen.io/rest-api-reference/files/search-files.md): Semantic vector search over your files. Returns the closest matching files ranked by cosine similarity.
- [Archive file](https://docs.videogen.io/rest-api-reference/files/archive-file.md): Archive a file by setting its archived timestamp. Archived files are excluded from list results.

- [Create entity](https://docs.videogen.io/rest-api-reference/entities/create-entity.md): Create a reusable actor, product, visual style, or slideshow theme entity.

- [Archive entity](https://docs.videogen.io/rest-api-reference/entities/archive-entity.md): Archive an entity so it is excluded from list results. Built-in entities cannot be archived.
- [Add entity reference](https://docs.videogen.io/rest-api-reference/entities/add-entity-reference.md): Add a reference asset (e.g. an image) to an entity. Built-in entities cannot have references added.

## Webhook events

- [Webhook events (site)](https://docs.videogen.io/webhook-events): Webhook event categories and registration overview.
- [Webhook events overview](https://docs.videogen.io/webhook-events.md): Event categories (tool execution, workflow run, project export, file upload, assistant message), delivery format, signature verification, and registration.

### Tool execution events

- [tool_execution.succeeded](https://docs.videogen.io/webhook-events/webhook-events/tool-execution-succeeded.md): Delivered when a tool execution completes successfully. Payload includes the executed tool's full result.
- [tool_execution.failed](https://docs.videogen.io/webhook-events/webhook-events/tool-execution-failed.md): Delivered when a tool execution finishes in a failed terminal state. Payload includes a machine-readable error code and message.
- [tool_execution.cancelled](https://docs.videogen.io/webhook-events/webhook-events/tool-execution-cancelled.md): Delivered when a tool execution is cancelled (via `POST /v1/tools/executions/{toolExecutionId}/cancel`).

### Workflow run events

- [workflow_run.succeeded](https://docs.videogen.io/webhook-events/webhook-events/workflow-run-succeeded.md): Delivered when a workflow run completes successfully. Payload includes `workflowRunId`, `workflowType`, `projectId`, and optional `projectUrl` (app editor link).
- [workflow_run.failed](https://docs.videogen.io/webhook-events/webhook-events/workflow-run-failed.md): Delivered when a workflow run finishes in a failed terminal state. Payload includes `workflowRunId`, `workflowType`, `projectId`, and an error message.
- [workflow_run.cancelled](https://docs.videogen.io/webhook-events/webhook-events/workflow-run-cancelled.md): Delivered when a workflow run is cancelled (via `POST /v1/workflows/runs/{workflowRunId}/cancel`).

### Project export events

- [project_export.succeeded](https://docs.videogen.io/webhook-events/webhook-events/project-export-succeeded.md): Delivered when a project export started via `POST /v1/projects/{projectId}/export` completes successfully. Payload includes `exportId`, `projectId`, and `exportFileId`.
- [project_export.failed](https://docs.videogen.io/webhook-events/webhook-events/project-export-failed.md): Delivered when a project export started via the API fails. Payload includes `exportId`, `projectId`, and an error message.
- [project_export.cancelled](https://docs.videogen.io/webhook-events/webhook-events/project-export-cancelled.md): Delivered when a project export started via the API is cancelled.

### File events

- [file.upload.completed](https://docs.videogen.io/webhook-events/webhook-events/file-upload-completed.md): Delivered when a file upload finishes and the file is stored. Only fired for files uploaded via the API.
- [file.upload.failed](https://docs.videogen.io/webhook-events/webhook-events/file-upload-failed.md): Delivered when an API file upload fails.
- [file.playback_ready](https://docs.videogen.io/webhook-events/webhook-events/file-playback-ready.md): Delivered when HLS streaming becomes available for a file (private `hlsSource`, plus public playback if enabled).
- [file.download_ready](https://docs.videogen.io/webhook-events/webhook-events/file-download-ready.md): Delivered when at least one static-rendition download URL is ready for a file.
- [file.analysis_completed](https://docs.videogen.io/webhook-events/webhook-events/file-analysis-completed.md): Delivered when description, transcript, and vector embedding are ready (the file is now searchable). Never fires for `scope: "TEMPORARY"` files.
- [file.analysis_failed](https://docs.videogen.io/webhook-events/webhook-events/file-analysis-failed.md): Delivered when file analysis fails. Never fires for `scope: "TEMPORARY"` files.

### Assistant message events

- [assistant_message.succeeded](https://docs.videogen.io/webhook-events/webhook-events/assistant-message-succeeded.md): Delivered when an assistant message completes successfully. Payload includes the assistant's reply and any suggested actions.
- [assistant_message.failed](https://docs.videogen.io/webhook-events/webhook-events/assistant-message-failed.md): Delivered when an assistant message finishes in a failed terminal state.
- [assistant_message.cancelled](https://docs.videogen.io/webhook-events/webhook-events/assistant-message-cancelled.md): Delivered when an assistant message is cancelled.

## Webhooks (REST)

- [List webhooks](https://docs.videogen.io/rest-api-reference/webhooks/list-webhook-endpoints.md): All webhook endpoints registered to the current API key. Cursor-paginated.
- [Create webhook](https://docs.videogen.io/rest-api-reference/webhooks/create-webhook-endpoint.md): Subscribe an HTTPS URL to `tool_execution.*`, `workflow_run.*`, `project_export.*`, `file.*`, and `assistant_message.*` events; the response is the only place `signingSecret` is returned.
- [Delete webhook](https://docs.videogen.io/rest-api-reference/webhooks/delete-webhook-endpoint.md): Unsubscribe an endpoint by id.

### Event types

Tool execution events: `tool_execution.succeeded`, `tool_execution.failed`, `tool_execution.cancelled`.

Workflow run events: `workflow_run.succeeded`, `workflow_run.failed`, `workflow_run.cancelled`. Payload includes `workflowRunId`, `workflowType`, `projectId`, and optional `projectUrl` (deep link to open the project in the VideoGen editor; not needed for API-only integrations; team and collaborators only).

Project export events (API exports only): `project_export.succeeded`, `project_export.failed`, `project_export.cancelled`. Payload includes `exportId`, `projectId`, `occurredAt`, and `exportFileId` (`null` until succeeded). Use `GET /v1/projects/{projectId}/exports/{exportId}` for signed download URLs.

File upload events (API uploads only): `file.upload.completed`, `file.upload.failed`, `file.playback_ready`, `file.download_ready`, `file.analysis_completed`, `file.analysis_failed`. Each payload includes a hydrated `FileInfo` object. `file.playback_ready` fires when HLS streaming (both private `hlsSource` and public if enabled) is available. `file.download_ready` fires when at least one static rendition download URL is ready. `file.analysis_completed` fires when description, transcript, and vector embedding are ready (the file is now included in search results). Temporary files (`scope: "TEMPORARY"`) are never analyzed, so `file.analysis_completed` and `file.analysis_failed` will never fire for them.

Assistant message events: `assistant_message.succeeded`, `assistant_message.failed`, `assistant_message.cancelled`. Delivered as an assistant message (from `startAssistantChat` or `sendAssistantMessage`) reaches a terminal state.
